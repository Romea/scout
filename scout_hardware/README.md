# scout_hardware

## 1) Overview

`scout_hardware` provides the live `ros2_control` hardware plugins for Scout mobile bases.

It specializes the generic `4WD` hardware abstraction from `romea_mobile_base_hardware` and connects it to the Scout low-level controller through the AGX CAN interface.

The exported plugins are:

| Plugin | Base class | Mobile base architecture | Model |
|---|---|---|---|
| `scout_hardware/ScoutMiniHardware` | `HardwareSystemInterface4WD` | `4WD` | Scout Mini |
| `scout_hardware/ScoutV2Hardware` | `HardwareSystemInterface4WD` | `4WD` | Scout V2 |

## 2) Hardware concept

`ScoutMiniHardware` and `ScoutV2Hardware` are loaded by `controller_manager` from the `<ros2_control>` description generated by `scout_description`.

At runtime, the common Scout hardware implementation:

1. reads the selected Scout `ros2_control` hardware information;
2. creates the `HardwareInterface4WD` command and state interface mapping;
3. loads track and wheel radius information;
4. connects to the Scout low-level controller on `can0`;
5. enables commanded mode;
6. converts four controller-side wheel speed commands into longitudinal and angular speed commands;
7. sends skid-steering speed commands to the robot;
8. exposes four wheel speed feedback values through `ros2_control` state interfaces.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController4WD` writes four wheel speed commands and reads wheel speed feedback from state interfaces to compute odometry.

The command path is implemented. The low-level actuator feedback decoding is still incomplete in the current hardware implementation and must be finished before relying on live odometry feedback.

## 3) CAN communication

The current implementation uses the AGX robotics SDK over SocketCAN on:

```text
can0
```

The hardware plugin sends:

* commanded-mode activation;
* longitudinal speed commands;
* angular speed commands;
* null commands when the interface is connected or disconnected.

It is expected to receive:

* front left wheel speed feedback;
* front right wheel speed feedback;
* rear left wheel speed feedback;
* rear right wheel speed feedback.

## 4) Relation with other packages

`scout_hardware` is the live hardware specialization of Scout mobile bases:

* `scout_description` selects `scout_hardware/ScoutMiniHardware` or `scout_hardware/ScoutV2Hardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `4WD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `scout_bringup` starts the controller manager and loads the selected hardware plugin in live mode.
